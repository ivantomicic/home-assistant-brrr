# Brrr Notifications

Send rich Brrr push notifications from Home Assistant's visual automation editor.

The integration supports multiple Brrr targets, notification threads, custom icons and images, sounds, interruption levels, critical volume, Focus filters, expiration dates, and tap URLs. Images can use public HTTPS URLs or an explicitly enabled temporary export from Home Assistant's Media Library.

After installation and restart, add **Brrr Notifications** from **Settings → Devices & services** and paste a webhook URL from the Brrr app.
